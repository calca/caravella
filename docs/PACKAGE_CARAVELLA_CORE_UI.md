# Package: `caravella_core_ui`

Shared design-system package: reusable widgets, themes, map building blocks. Depends only on `caravella_core` among local packages (see [Architecture Overview](ARCHITECTURE.md)). Import as a whole: `import 'package:caravella_core_ui/caravella_core_ui.dart';` — avoid deep-importing individual widget files.

**Before building any new screen, dialog, card, or chart in `lib/`, check here first.** This page is the catalog.

## Map widgets (`lib/map/`)

Built on **`flutter_map`** (OpenStreetMap tiles) + **`latlong2`**:

- `MapTileLayerWidget` — centralizes the OSM tile layer config (`tile.openstreetmap.org`, `userAgentPackageName`; tile-load errors only reach an optional `MapTileStatus`).
- `StandardMap` — the entry point for any new map screen: always includes the tile layer, pass markers/polylines via `layers`, and a `MapTileStatus` as `tileStatus` to follow the tiles.
- `computeBounds(points, {minSpanDegrees})` — bounding box for a set of points, expanding near-degenerate spans so camera fit doesn't over-zoom.
- `MapLoadingOverlay`, `MapUnavailableCard` — the pill while tiles are slow and the card with Try again when they fail, both driven by a `MapTileStatus`.
- `MapErrorOverlay`, `MapErrorState`, `MapEmptyState`, `MapNoResultsMessage` — presentational overlays for common map states.

See [Location & Maps](LOCATION_AND_MAPS.md) for how these compose with the geocoding/search pipeline.

## Themes (`lib/themes/`)

- **`caravella_themes.dart`** — hand-authored Material 3 `ColorScheme` consts: `lightColorScheme` (primary `0xFF00736A`, a darker shade of the brand teal `0xFF009688` so it passes 4.5:1 as text; the icon/splash keep `0xFF009688`) and `darkColorScheme` (a custom "soft dark" scheme tuned for WCAG AA contrast). `CaravellaThemes.createLightTheme({dynamicColorScheme})` / `createDarkTheme(...)` build full `ThemeData` (Material 3, `AppTypography.fontFamily`, custom text theme, dialog/input decoration themes), supporting Android dynamic color (Material You) with a fallback to the hardcoded scheme's container shades. Text fields use an `outline` underline (≥3:1 non-text contrast), 2 px `primary` when focused. Precomputed statics: `CaravellaThemes.light` / `.dark`. `test/themes/theme_contrast_test.dart` enforces the WCAG AA ratios of both schemes — run it after changing any color. Also defines the `CaravellaSemanticColors` extension on `ColorScheme` — `.success`/`.onSuccess`/`.warning`/`.onWarning`, plus `.raisedSurface` (fill for elements that sit above the `surfaceContainer` page: white in light, `surfaceContainerHighest` in dark — never use `surfaceContainerLowest` for that, it is near-black in dark), `.budgetFill`/`.budgetTrack`/`.budgetOver`/`.onBudgetOver` (the budget ring and bars: grey within the budget, muted amber over it, never red; ≥3:1 as graphics, `.onBudgetOver` ≥4.5:1 as text), contrast-checked (≥4.5:1) against `surface` in both themes — use these instead of ad hoc `Colors.green`/`Colors.amber` for "ok/attention" status (there's no `.error` counterpart: Material 3's own `ColorScheme.error`/`.onError` already cover that role). Text roles (`onSurface`, `onSurfaceVariant`, `outline`, `primary`, `error`) keep ≥4.5:1 on `surface`, `surfaceContainer` and `raisedSurface` in both themes, on-colors on their fills too, and `success`/`warning` ≥3:1 as icons/dots — `test/themes/contrast_test.dart` guards it.
- **`app_text_styles.dart`** — `AppTypography.fontFamily` (`'Montserrat'`), the single source of truth for the app font family — never hardcode the string elsewhere. `AppTextStyles` convenience tokens: `sectionTitle`, `listItem`, `listItemStrong`, `subtle` (all derived from `Theme.of(context).textTheme`), plus non-theme-derived `static const TextStyle` tokens for fixed-background contexts: `mediaOverlayMessage`/`mediaOverlayCaption` (white text over the fixed black background of image/video/PDF viewers) and `emojiDisplay` (72pt, the wizard's emoji picker steps).
- **`app_dimens.dart`** — `AppDimens.minTouchTarget` (48.0) / `.minTouchTargetCompact` (44.0) / `.minTouchTargetInline` (24.0, WCAG 2.5.8 floor for targets embedded in a text flow), the shared touch-target constants. Prefer these over hardcoding `Size(48, 48)`/`44`/etc. on `styleFrom(minimumSize: ...)`.
- **The layout grid** (every screen, checked against screenshots in 2.5): cards, lists, pill selectors and the round top buttons sit **16** from the screen's edges; page titles, eyebrows and section labels at **20** (the label 4 in from the card under it: `SettingsLabel`, its style `SettingsLabel.styleOf` for every section label, on settings pages and the group page's Balances and Statistics; `FormSectionLabel` sits on the line of the pills and fields under it, and the expense form is at 20 like the sheet); the text inside cards at **30** (14 of padding: `SettingsTile`, Home's cards, Balances, Statistics, the group page's header). Vertically: 20 from a page title to its first content (`SettingsScaffold`), 12 between cards of a section, 20 above a section label, 12 under the group page's section selector. Sheets follow the same grid (`CaravellaBottomSheetScaffold`, the second screens of `SheetPager`, the selection sheet): cards and buttons at 16, title and text written straight on the sheet at 20; a note under a card sits at 20 too.
- **`app_spacing.dart`** — `AppSpacing` padding/gap scale derived from the values already dominant in the app (`xxs`=4, `xs`=8, `sm`=12, `md`=16, `lg`=20, `xl`=24, `xxl`=32). Use these instead of hardcoding `EdgeInsets`/`SizedBox` numbers in new shared components; existing call sites are migrated incrementally (see `plan.todo.ds.md`), not all at once.
- **`app_radius.dart`** — `AppRadius` corner-radius scale (`xs`=4, `sm`=8, `md`=12, `lg`=16, `dialog`=28 — the Material 3 large-shape dialog radius, used by `Material3Dialog` and `CaravellaThemes`' dialog theme). `BaseCard`'s default radius is `AppRadius.lg`.
- **`app_motion.dart`** — `AppMotion.sheet`, the `AnimationStyle` of every modal sheet (320 ms ease-out in, 220 ms out), applied by `showAppBottomSheet`.
- **`form_theme.dart`** — `FormTheme` spacing constants (`fieldSpacing`, `sectionSpacing`, ...) aliased to `AppSpacing` so form spacing stays in sync with the rest of the scale, plus `iconSpacing` (6.0, inline icon-to-text gap fine-tuned for forms — intentionally not on the general scale) and decoration builders: `getStandardDecoration`, `getMultilineDecoration`, `getBorderlessDecoration` (no border in any state — enabled, focused, disabled — so the theme's underline never shows inside a card; all three accept an optional `labelText` alongside `hintText` — prefer it for real form fields, since a hint alone disappears once the user types, see WCAG 3.3.2), `getBorderlessAmountDecoration` (large amount entry, hint-only by design), `getCardDecoration` (a raised rounded field on a grey page — fill, hairline, 2dp focus border, error border; the expense form's description and note), `getSearchPillDecoration` (28dp pill search field, hint-only by design). The standard, multiline and borderless decorations set `constraints: BoxConstraints(minHeight: FormTheme.minFieldHeight)` (48dp) so dense fields still meet the minimum touch target.

Text: prefer `Text.rich` over `RichText` — `RichText` ignores the system text size unless given a `textScaler`. Light-theme `outline` (#666666) doubles as the secondary-text color and is ≥4.5:1 on every light surface (WCAG AA); don't use `onSurface`/`onSurfaceVariant` at low alpha for readable text.

Always match these tokens instead of hardcoding spacing/shape/text values. `validate_design_tokens.sh` guards the highest-risk regressions (see `plan.todo.ds.md`) in CI.

## Utilities

- **`Debouncer`** (`lib/utils/debounce.dart`) — `Debouncer(duration: ...)`; `.call(callback)` cancels+reschedules, `.cancel()`/`.dispose()`. Typical use: debounced search-as-you-type.

## Dependencies

Local: `caravella_core` only. Third-party: `fl_chart`, `flutter_map` + `latlong2`, `intl`, `timeago`, `zentoast` (toast backend). Bundles its own `Montserrat` font (`assets/fonts/`), used as the app-wide default font family.
